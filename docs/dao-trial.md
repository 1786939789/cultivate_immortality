# 问道秘境规格与验收矩阵

## 目标

问道秘境升级为周期式深潜挑战：前 15 层提供稳定内容，15 层后进入无尽问天阶；排行优先比较最高层数，同层再比较评分。评分、奖励、同行贡献和局内构筑都必须可解释、可回放、可迁移。

## 固定规则

- 三条路线保留：金石关、风雷径、玄阴泽。
- 每期路线和节点使用周期种子确定；同周期同路线的正式挑战节点一致。
- 第 5、10、15 层为阶段首领并开放安全离境；第 15 层后每 5 层生成一个无尽阶段。
- 正式挑战消耗问道签，演练不发放奖励、不进入正式最佳记录。
- 排行键为 `maxFloor DESC, score DESC, qualityScore DESC`。
- 分数不因死亡或撤离折损；奖励留存比例单独结算。
- 同行入场时保存 NPC 战力与战斗属性快照，同行支援受真实战力和关系共同影响。
- 道印是小型增益；问道法则是机制型增益，使用固定触发器，不允许任意脚本改变战斗顺序。

## 状态契约

`daoTrial.version` 升至 3。旧历史保留；旧的 7 节点进行中挑战在首次读取时转换为兼容记录并安全结束，不丢失问道签、历史和路线精通。

`activeRun` 新增：

- `floor`, `maxFloor`, `checkpointFloor`
- `scoreBreakdown`: progress / quality / risk / build / total
- `combatStats`: rounds / damageDealt / damageTaken / healing / shields / skillCasts / manaSpent
- `companionSnapshot`: person / power / stats / archetype / relationFactor / supportFactor
- `companionContribution`: damage / healing / shields / control / assists
- `lawIds`, `lawOffer`, `lawNonce`

## 验收编号

- `LEVEL-01`: 前 15 层和第 5、10、15 层首领可确定性生成。
- `LEVEL-02`: 第 16 层以后可持续生成，节点、敌人和词条不会重复导致卡死。
- `SCORE-01`: 层数增加时进度分严格递增。
- `SCORE-02`: 同层生存、速胜、运转和战术细节能拉开评分。
- `SCORE-03`: 失败、撤离、成功的分数不折损，奖励按留存比例结算。
- `COMP-01`: 同行支援读取 NPC 实际战力快照。
- `COMP-02`: 强同行在相同关系下贡献不低于弱同行，且有上限。
- `COMP-03`: 同行在回放和结算中产生可见贡献。
- `LAW-01`: 法则使用统一触发器并保持确定性。
- `LAW-02`: 18 个法则均有配置、展示、触发和边界测试。
- `SAVE-01`: 旧存档读取、跨周期、重启和并发保存不损坏秘境状态。
- `UI-01`: 路线、层数、评分拆分、同行贡献、法则选择和历史均可操作和查看。
- `E2E-01`: 从选路线到阶段离境、回放、历史和排行完成一条完整流程。

## 分阶段门槛

1. 状态契约和确定性层级测试通过。
2. 评分与奖励路径测试通过，前端能显示拆分。
3. 同行快照、行动、回放和统计测试通过。
4. 法则触发器和 18 个法则测试通过。
5. 长期记录、路线精通、旧存档迁移和构建通过。
6. 浏览器完成正式挑战、撤离、失败、刷新恢复和历史回放。
